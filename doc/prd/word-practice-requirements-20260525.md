# 小柚英语单词练习功能需求文档

> 日期：2026-05-25
> 状态：待评审
> 适用范围：微信小程序、PC 管理后台、后端 API、MySQL 数据模型、AI 生成服务

## 1. 项目概述

### 1.1 产品类型

在现有小柚英语系统中新增“单词练习”模块。PC 管理后台负责通过 AI 大模型生成、管理和发布单词本；微信小程序负责用户学习、复习和个人进度记录。

### 1.2 一句话目标

管理员可以基于具体场景或已有口语主题批量生成分难度单词本，用户可以在小程序中按记忆曲线持续学习和复习，直到连续 4 次认识后标记为完全掌握。

### 1.3 目标用户

- 普通学习用户：在微信小程序中学习和复习单词。
- 会员用户：沿用现有学习中心权限，优先作为单词练习的目标用户。
- 管理员/运营人员：在 PC 后台创建单词本、AI 生成单词、编辑、发布、下架和维护内容。

### 1.4 平台范围

- 微信小程序：新增首页入口、学习中心入口、单词本列表、单词练习、单词详情、学习进度。
- PC 管理后台：新增单词本设置、AI 生成、单词管理、批量操作、主题关联生成。
- 后端服务：新增管理端和用户端 API，新增单词本、单词、用户学习进度等数据表。

### 1.5 成功定义

- 管理员能在后台创建多个单词本，并按场景或口语主题生成初级/进阶单词。
- 单词内容完整落库，包括解释、例句、句型、音标、美式和英式发音音频 URL；单词和例句音频由后台可配置的 TTS 模型生成并保存到服务端本地。
- 同一个单词本内英文单词完全相同的内容不会重复出现。
- 用户能在小程序学习单词、查看详情、记录认识/不认识，并根据复习间隔再次出现。
- 用户连续 4 次复习选择“认识”后，单词状态变为已掌握。

## 2. 产品目标与非目标

### 2.1 目标

- 建立后台可维护的单词本体系，支持多个单词本。
- 支持每个单词本设置初级和进阶两个学习难度。
- 支持 AI 根据“具体场景”批量生成单词。
- 支持 AI 根据已有口语主题批量生成主题相关单词。
- 支持新建口语主题后提示管理员是否向某个单词本补充词汇。
- 支持小程序用户按单词本学习，按个人学习进度复习。
- 支持成熟但不过度复杂的记忆曲线规则。

### 2.2 非目标

- v1 不做拼写题、听音选词、英选中、中选英等测验题型。
- v1 不做排行榜、打卡海报、社交分享和用户间 PK。
- v1 不做复杂自定义记忆算法配置。
- v1 不做用户自建单词本。
- v1 不做离线下载音频。

## 3. 用户角色与权限

### 3.1 普通用户

- 可以浏览已发布的单词本。
- 可以选择单词本和难度开始学习。
- 可以查看自己的学习进度。
- 可以查看已学单词和已掌握单词。
- 不能创建、编辑、删除单词本或单词。

### 3.2 会员用户

- 单词练习不再作为会员专属功能；会员用户与普通登录用户拥有相同的单词本使用权限。
- 学习中心仍保留独立会员权限，单词练习不复用学习中心会员拦截规则。

### 3.3 管理员

- 可以创建、编辑、删除单词本。
- 可以发布、下架单词本。
- 可以通过 AI 生成初级/进阶单词。
- 可以编辑、删除、发布、下架单词。
- 可以批量发布、下架、删除、调整排序、重新生成音频。
- 可以查看单词来源主题和关联关系。
- 可以在创建口语主题后触发单词补充流程。

## 4. V1 范围

### 4.1 V1 必须包含

- PC 后台单词本列表、创建、编辑、删除、发布、下架。
- PC 后台单词列表，支持按单词本、难度、发布状态、来源主题筛选。
- PC 后台 AI 场景生成单词。
- PC 后台 AI 口语主题生成单词。
- PC 后台单词编辑详情。
- PC 后台批量发布、下架、删除、调整排序、重新生成音频。
- 新建口语主题成功后弹窗提示是否补充单词。
- 小程序首页增加单词练习入口。
- 小程序学习中心增加单词练习入口。
- 小程序单词本列表。
- 小程序单词练习页：先展示英文单词，用户选择“认识”或“不认识”。
- 小程序单词详情页：用户点击后查看完整内容并播放发音。
- 用户学习进度和复习计划。
- 按固定复习间隔安排复习。

### 4.2 后续可选

- 多题型测验：英选中、中选英、拼写、听音选词。
- 每日学习目标和提醒。
- 学习日历、连续学习天数和打卡分享。
- 错词本和收藏夹。
- 用户自定义单词本。
- 单词掌握度报表。

### 4.3 明确不做

- 不允许普通用户在小程序新增或修改后台单词内容。
- 不在 v1 中开放提示词自由编辑。
- 不做全系统英文单词唯一限制，只做同一单词本内去重。

## 5. 核心用户流程

### 5.1 管理员按场景生成单词本

- 入口：PC 后台“单词训练/单词本设置”。
- 步骤：
  1. 管理员创建单词本，填写名称、描述、适用场景、发布状态。
  2. 选择生成方式为“按场景生成”。
  3. 输入场景描述、生成数量、难度、AI 模型。
  4. 系统使用内置提示词调用 AI。
  5. 系统解析 AI 返回结果，校验字段完整性。
  6. 系统按单词本内英文单词去重。
  7. 系统保存单词、解释、例句、句型、音标、难度、来源场景。
  8. 系统调用后台配置的 TTS 模型，分别生成单词美式发音、单词英式发音、例句美式发音、例句英式发音。
  9. 系统将音频文件保存到服务端本地存储目录，并将可访问音频 URL 落库。
  8. 管理员查看结果，可编辑、删除、发布或下架。
- 成功结果：单词出现在指定单词本中，小程序可按发布状态展示。
- 异常路径：
  - AI 返回格式错误：提示生成失败，不写入或只写入校验通过的内容。
  - 音频生成失败：保存单词内容，音频状态标记为失败，允许批量重新生成音频。
  - 全部重复：提示没有新增单词。

### 5.2 管理员按口语主题生成单词

- 入口：PC 后台单词本详情，或口语主题创建成功后的弹窗。
- 步骤：
  1. 管理员选择一个或多个口语主题。
  2. 选择目标单词本。
  3. 分别设置初级数量和进阶数量。
  4. 选择 AI 模型。
  5. 系统基于主题标题、中文标题、标签、讨论问题生成相关单词。
  6. 系统保存单词并记录来源主题。
  7. 同一单词本内已存在的英文单词不重复写入。
- 成功结果：目标单词本补充主题相关词汇，单词详情可显示来源口语主题。

### 5.3 用户学习新单词

- 入口：小程序首页或学习中心的“单词练习”入口。
- 步骤：
  1. 用户进入单词本列表。
  2. 选择一个已发布单词本。
  3. 选择初级或进阶难度。
  4. 系统优先展示到期复习词；若没有到期复习词，则展示未学新词。
  5. 页面先只展示英文单词和发音入口。
  6. 用户选择“认识”或“不认识”。
  7. 如果用户不认识，可点击查看详情。
  8. 系统记录结果并计算下次复习时间。
- 成功结果：用户学习进度更新，下一词继续展示。

### 5.4 用户复习单词

- 入口：单词练习页自动混入到期复习词。
- 步骤：
  1. 系统查询用户在该单词本和难度下到期复习的单词。
  2. 用户对每个词选择“认识”或“不认识”。
  3. 选择“认识”时连续认识次数加 1。
  4. 选择“不认识”时连续认识次数重置为 0。
  5. 连续认识次数达到 4 时，单词标记为已掌握。
- 成功结果：已掌握词不再进入每日必复习列表，但用户仍可在单词本内查看。

## 6. 功能需求

### FR-1 单词本管理

- 目标：管理员可以维护多个单词本。
- 输入：名称、描述、适用场景、关联主题、发布状态。
- 输出：单词本列表、详情和统计。
- 业务规则：
  - 单词本名称不能为空。
  - 单词本可发布或下架。
  - 下架单词本不在小程序普通用户侧展示。
  - 删除单词本时，应同时处理其单词和用户进度，建议 v1 采用软删除。
- 权限：仅管理员。
- 状态：草稿/已发布/已下架/已删除。

验收标准：

- [ ] 管理员可以创建、编辑、删除、发布、下架单词本。
- [ ] 小程序只展示已发布单词本。
- [ ] 单词本详情能显示初级/进阶单词数量、已发布数量、关联主题数量。

### FR-2 单词内容管理

- 目标：管理员可以维护单词本中的单词。
- 必填字段：
  - 英文单词
  - 难度：`beginner` 或 `advanced`
  - 中文释义
  - 英文释义
  - 美式发音音频 URL
  - 英式发音音频 URL
  - 例句美式发音音频 URL
  - 例句英式发音音频 URL
- 可选字段：
  - 音标
  - 词性
  - 常用搭配/常用句型
  - 英文例句
  - 中文例句翻译
  - 来源场景
  - 来源口语主题
  - 发布状态
- 不需要字段：
  - AI 生成批次
  - 排序号作为详情展示字段
- 业务规则：
  - 同一个单词本内，英文单词完全相同视为重复。
  - 去重比较默认忽略首尾空格，建议英文单词按小写归一化后比较。
  - 初级和进阶中如果英文完全相同，也属于同一单词本内重复，不重复创建。
  - 后台内部仍需要排序字段支持批量调整排序，但不在小程序单词详情中展示。

验收标准：

- [ ] 管理员可以查看、搜索、筛选、编辑、删除单词。
- [ ] 管理员无法在同一个单词本中创建英文完全相同的重复单词。
- [ ] 单词保存后，小程序详情页展示对应内容。

### FR-3 AI 按场景生成单词

- 目标：管理员可以基于具体学习场景生成单词。
- 输入：
  - 目标单词本
  - 场景描述
  - 生成数量
  - 难度：初级/进阶
  - AI 模型
- 输出：结构化单词列表并落库。
- 业务规则：
  - 使用系统内置提示词，不提供自由编辑提示词。
  - AI 应返回结构化 JSON。
  - 系统应要求 AI 按语义相关性组织单词顺序，使相关词相邻。
  - 保存前执行字段校验和单词本内去重。
  - AI 文本生成的每个单词都要包含释义、例句、句型、音标。
  - 文本生成完成后，系统必须调用 TTS 模型生成单词和例句的美式、英式发音音频，并保存到本地。

验收标准：

- [ ] 管理员输入场景、数量、难度和模型后可以生成单词。
- [ ] 生成结果能保存到目标单词本。
- [ ] 重复单词不会再次写入。
- [ ] AI 返回异常时页面显示清晰错误。

### FR-4 AI 按口语主题生成单词

- 目标：管理员可以使用已有口语主题生成主题相关单词。
- 输入：
  - 目标单词本
  - 一个或多个口语主题
  - 每个主题初级生成数量
  - 每个主题进阶生成数量
  - AI 模型
- 输出：关联主题的单词列表。
- 业务规则：
  - 系统应将主题英文标题、中文标题、标签、讨论问题作为 AI 上下文。
  - 初级和进阶分别生成。
  - 单词保存时记录来源主题 ID 和主题标题。
  - 一个单词可关联一个或多个来源主题。
  - 同一单词本内重复英文单词不重复写入；若重复但来源主题不同，应补充关联关系。

验收标准：

- [ ] 管理员可以选择主题并生成单词。
- [ ] 生成后的单词能显示来源主题。
- [ ] 重复单词不会新增重复记录，但可以增加来源主题关联。

### FR-5 新建主题后的单词补充提示

- 目标：管理员创建口语主题后，可顺手给单词本补充相关词。
- 触发：PC 后台创建口语主题成功。
- 交互：
  - 弹窗提示：“是否为单词本补充该主题相关词汇？”
  - 管理员可选择目标单词本、初级数量、进阶数量、模型。
  - 管理员也可跳过。
- 业务规则：
  - 跳过不影响主题创建结果。
  - 生成过程失败不回滚已创建主题。

验收标准：

- [ ] 创建主题成功后出现补充词汇提示。
- [ ] 点击跳过后弹窗关闭，主题保留。
- [ ] 点击生成后进入主题单词生成流程。

### FR-6 小程序单词练习入口

- 目标：用户能从首页和学习中心进入单词练习。
- 入口：
  - 小程序首页增加“单词练习”入口。
  - 小程序学习中心增加“单词练习”入口。
- 业务规则：
  - 未登录用户点击后引导登录。
  - 非会员用户点击后按现有学习中心逻辑引导开通或兑换会员。

验收标准：

- [ ] 首页入口可跳转到单词本列表。
- [ ] 学习中心入口可跳转到单词本列表。
- [ ] 未授权用户看到正确引导。

### FR-7 小程序单词本与难度选择

- 目标：用户可选择单词本和学习难度。
- 展示信息：
  - 单词本名称
  - 描述
  - 初级/进阶词数
  - 用户学习进度：已学、待复习、已掌握
- 业务规则：
  - 每个单词本可切换初级和进阶。
  - 默认进入初级。

验收标准：

- [ ] 用户可以查看已发布单词本列表。
- [ ] 用户可以进入单词本并切换初级/进阶。
- [ ] 进度统计与用户个人记录一致。

### FR-8 小程序单词练习页

- 目标：用户按“先回忆，再反馈”的方式学习。
- 默认展示：
  - 英文单词
  - 发音播放按钮
  - “认识”按钮
  - “不认识”按钮
  - “查看详情”入口
- 详情展示：
  - 单词
  - 音标
  - 美式和英式发音
  - 词性
  - 中文释义
  - 英文释义
  - 常用搭配/句型
  - 英文例句
  - 中文例句翻译
  - 例句美式和英式发音
  - 难度
  - 来源场景
  - 来源口语主题
- 业务规则：
  - 用户想学多少学多少，v1 不限制每日学习数量。
  - 到期复习词优先展示，新词在没有到期复习词时展示。
  - 用户点击“不认识”后允许立即查看详情。

验收标准：

- [ ] 页面初始只突出英文单词，不直接暴露释义。
- [ ] 用户点击查看详情后能看到完整字段。
- [ ] 点击认识/不认识后记录学习结果并进入下一词。

### FR-9 用户学习进度与记忆曲线

- 目标：系统为每个用户记录每个单词的学习状态。
- 状态：
  - 未学习
  - 学习中
  - 待复习
  - 已掌握
- 复习规则：
  - 新词第一次学习后，如果选择“认识”，连续认识次数变为 1，次日复习。
  - 连续认识次数为 1/2/3/4 时，复习间隔分别为 1 天/3 天/7 天/15 天。
  - 任意一次选择“不认识”，连续认识次数重置为 0，次日再次复习。
  - 连续 4 次选择“认识”后，标记为已掌握。
  - 已掌握词不再进入每日必复习列表，但仍可查看。
- 记录字段：
  - 用户 ID
  - 单词 ID
  - 单词本 ID
  - 难度
  - 状态
  - 连续认识次数
  - 学习次数
  - 认识次数
  - 不认识次数
  - 首次学习时间
  - 最近学习时间
  - 下次复习时间
  - 掌握时间

验收标准：

- [ ] 每个用户拥有独立学习进度。
- [ ] 复习时间按规则计算。
- [ ] 连续 4 次认识后状态变为已掌握。
- [ ] 点不认识会重置连续认识次数。

## 7. 页面与 UI/UX 要求

### 7.1 PC 后台视觉方向

- 沿用现有 Next.js 后台的浅色工具型风格。
- 使用固定侧边栏和顶栏结构。
- 表格、筛选栏、弹窗、批量操作条应与现有后台一致。
- 操作入口使用清晰按钮和图标，不做营销式大 Hero。

### 7.2 PC 页面清单

#### 页面 A：单词本管理

- 目的：管理多个单词本。
- 关键信息：名称、状态、初级词数、进阶词数、已发布词数、关联主题数、更新时间。
- 主要操作：新建、编辑、发布、下架、删除、进入详情。
- 空状态：提示创建第一个单词本。
- 加载状态：表格骨架或 loading。
- 错误状态：显示接口错误并允许重试。

#### 页面 B：单词本详情/单词列表

- 目的：管理某个单词本中的单词。
- 关键信息：单词、难度、释义摘要、来源主题、状态、更新时间。
- 筛选：难度、发布状态、来源主题、关键词。
- 主要操作：AI 生成、单个编辑、批量发布、批量下架、批量删除、批量调整排序、批量重新生成音频。
- 空状态：提示通过 AI 生成或手动新增。

#### 页面 C：AI 生成单词弹窗

- 目的：发起 AI 生成任务。
- 模式：
  - 按场景生成
  - 按口语主题生成
- 字段：
  - 目标单词本
  - 场景描述或主题选择
  - 初级/进阶数量
  - 难度
  - AI 模型
- 状态：
  - 生成中禁用提交按钮。
  - 生成成功展示新增数量、重复跳过数量、失败数量。
  - 生成失败展示错误信息。

#### 页面 D：单词编辑弹窗/页面

- 目的：编辑单词详情。
- 字段：见 FR-2。
- 主要操作：保存、取消、删除、重新生成音频。
- 校验：英文单词、难度、中文释义、英文释义必填；发布前应具备单词美式/英式音频和例句美式/英式音频，音频缺失时提示重新生成。

#### 页面 E：主题创建后的补充词汇弹窗

- 目的：在新主题创建后补充主题词汇。
- 主要操作：选择单词本、设置数量、选择模型、开始生成、跳过。
- 失败状态：生成失败不影响已创建主题。

### 7.3 小程序页面清单

#### 页面 F：首页入口

- 目的：让用户发现单词练习。
- 位置：现有首页学习入口附近。
- 行为：点击进入单词本列表。

#### 页面 G：学习中心入口

- 目的：将单词练习纳入学习中心。
- 位置：现有学习中心入口区。

#### 页面 H：单词本列表

- 目的：展示可学习单词本。
- 关键信息：名称、描述、初级/进阶词数、用户进度。
- 主要操作：进入单词本。
- 空状态：暂无可学习单词本。

#### 页面 I：单词本学习首页

- 目的：切换难度并查看学习概览。
- 关键信息：当前难度、总词数、已学、待复习、已掌握。

#### 页面 J：单词练习页

## 8. 数据模型建议

### 8.1 `word_books`

- `id`：主键
- `name`：单词本名称
- `description`：描述
- `scenario`：适用场景描述
- `status`：`DRAFT`、`PUBLISHED`、`OFFLINE`
- `created_by`：创建管理员 ID
- `created_at`：创建时间
- `updated_at`：更新时间
- `deleted_at`：软删除时间

### 8.2 `word_book_topics`

- `id`：主键
- `word_book_id`：单词本 ID
- `topic_id`：口语主题 ID
- `created_at`：创建时间

### 8.3 `words`

- `id`：主键
- `word_book_id`：单词本 ID
- `word`：英文单词
- `normalized_word`：归一化英文单词，用于去重
- `difficulty`：`BEGINNER`、`ADVANCED`
- `phonetic`：音标
- `part_of_speech`：词性
- `definition_zh`：中文释义
- `definition_en`：英文释义
- `common_patterns`：常用搭配/句型，建议 JSON
- `example_en`：英文例句
- `example_zh`：中文例句翻译
- `audio_us_url`：美式发音音频 URL
- `audio_uk_url`：英式发音音频 URL
- `example_audio_us_url`：例句美式发音音频 URL
- `example_audio_uk_url`：例句英式发音音频 URL
- `audio_status`：音频生成状态，建议 `PENDING`、`READY`、`FAILED`
- `audio_error`：最近一次音频生成失败原因
- `source_scene`：来源场景
- `status`：`DRAFT`、`PUBLISHED`、`OFFLINE`
- `sort_order`：后台排序字段
- `created_at`：创建时间
- `updated_at`：更新时间
- `deleted_at`：软删除时间

约束建议：

- `word_book_id + normalized_word` 建唯一索引，满足同一单词本内去重。

### 8.4 `word_topics`

- `id`：主键
- `word_id`：单词 ID
- `topic_id`：口语主题 ID
- `topic_title_en`：冗余英文标题，便于展示
- `topic_title_zh`：冗余中文标题，便于展示
- `created_at`：创建时间

### 8.5 `user_word_progress`

- `id`：主键
- `user_id`：用户 ID
- `word_book_id`：单词本 ID
- `word_id`：单词 ID
- `difficulty`：`BEGINNER`、`ADVANCED`
- `status`：`NEW`、`LEARNING`、`REVIEWING`、`MASTERED`
- `consecutive_known_count`：连续认识次数
- `study_count`：学习次数
- `known_count`：认识次数
- `unknown_count`：不认识次数
- `first_studied_at`：首次学习时间
- `last_studied_at`：最近学习时间
- `next_review_at`：下次复习时间
- `mastered_at`：掌握时间
- `created_at`：创建时间
- `updated_at`：更新时间

约束建议：

- `user_id + word_id` 建唯一索引，保证一个用户对一个单词只有一条进度。

## 9. API 需求建议

### 9.1 管理端 API

所有接口需要管理员权限，路径建议使用 `/api/admin/word-books`。

- `GET /api/admin/word-books`：分页查询单词本。
- `POST /api/admin/word-books`：创建单词本。
- `GET /api/admin/word-books/{id}`：查询单词本详情。
- `PUT /api/admin/word-books/{id}`：更新单词本。
- `PATCH /api/admin/word-books/{id}/publish`：发布单词本。
- `PATCH /api/admin/word-books/{id}/offline`：下架单词本。
- `DELETE /api/admin/word-books/{id}`：删除单词本。
- `GET /api/admin/word-books/{id}/words`：分页查询单词。
- `POST /api/admin/word-books/{id}/words`：手动新增单词。
- `PUT /api/admin/words/{wordId}`：编辑单词。
- `DELETE /api/admin/words/{wordId}`：删除单词。
- `POST /api/admin/word-books/{id}/generate-by-scene`：按场景 AI 生成。
- `POST /api/admin/word-books/{id}/generate-by-topics`：按口语主题 AI 生成。
- `POST /api/admin/words/batch-publish`：批量发布。
- `POST /api/admin/words/batch-offline`：批量下架。
- `POST /api/admin/words/batch-delete`：批量删除。
- `POST /api/admin/words/batch-sort`：批量调整排序。
- `POST /api/admin/words/batch-regenerate-audio`：批量重新生成音频。

### 9.2 小程序用户端 API

路径建议使用 `/api/word-practice`。权限为登录用户，不限制会员状态。

- `GET /api/word-practice/books`：查询已发布单词本和个人进度摘要。
- `GET /api/word-practice/books/{bookId}`：查询单词本详情和难度统计。
- `GET /api/word-practice/books/{bookId}/next?difficulty=BEGINNER`：获取下一批待练习单词，优先到期复习词。
- `GET /api/word-practice/words/{wordId}`：查询单词详情。
- `POST /api/word-practice/words/{wordId}/answer`：提交认识/不认识。
- `GET /api/word-practice/books/{bookId}/progress`：查询当前用户单词本进度。
- `GET /api/word-practice/books/{bookId}/words`：查询单词本全部单词和用户状态。

### 9.3 关键请求响应示例

提交学习结果：

```json
{
  "difficulty": "BEGINNER",
  "result": "KNOWN"
}
```

响应：

```json
{
  "wordId": 123,
  "status": "REVIEWING",
  "consecutiveKnownCount": 2,
  "nextReviewAt": "2026-05-28T10:00:00",
  "mastered": false
}
```

## 10. AI 与外部服务

### 10.1 AI 模型

- 复用现有 `AiService` 和 `ai_models` 模型配置。
- 生成时管理员可选择模型。
- 不提供提示词自由编辑。
- 提示词由系统内置，并明确要求返回严格 JSON。

### 10.2 TTS 音频生成与本地存储

- 单词发音使用 TTS 模型生成，不依赖前端实时朗读。
- TTS 模型需要支持在 PC 后台配置，类似现有 AI 模型配置能力。
- 生成单词时，系统先调用文本生成模型生成结构化单词内容，再调用 TTS 模型生成音频。
- 每个单词至少生成 4 个音频文件：
  - 单词美式发音
  - 单词英式发音
  - 英文例句美式发音
  - 英文例句英式发音
- TTS 调用应使用系统内置提示词或固定参数，要求生成清晰、自然、适合英语学习的发音。
- 系统应将音频文件保存到服务端本地目录，例如 `/uploads/word-audio/{wordId}/...`。
- 数据表保存音频文件的可访问 URL 或相对路径，供小程序和 PC 后台播放。
- 音频文件命名应稳定且避免冲突，建议包含单词 ID、音频类型、口音类型和时间戳或内容哈希。
- 音频生成失败时，单词内容可保存，但 `audio_status` 应标记为 `FAILED`，并记录失败原因。
- 后台支持对单个或多个单词重新生成音频。重新生成成功后更新本地文件和音频 URL。

### 10.3 TTS 模型后台配置

- PC 后台需要支持配置 TTS 模型。
- 配置字段建议包括：
  - 模型名称
  - API 地址
  - API Key
  - 模型标识
  - 供应商类型
  - 是否默认 TTS 模型
  - 美式发音 voice 参数
  - 英式发音 voice 参数
  - 输出格式，例如 `mp3`
  - 启用状态
- 管理员发起单词生成或重新生成音频时，系统默认使用默认 TTS 模型，也可在生成弹窗中选择可用 TTS 模型。
- API Key 不得明文展示给前端，编辑时应采用脱敏展示或重新填写。

## 11. 非功能需求

### 11.1 性能

- 小程序单词练习接口单次响应建议小于 800ms，不包含首次 AI 生成。
- 后台单词列表必须分页。
- AI 生成任务可能耗时较长，前端需显示生成中状态，后端建议设置合理超时。

### 11.2 安全

- 管理端 API 仅管理员可访问。
- 用户端进度接口只能读写当前登录用户的数据。
- AI 模型 API Key 不得返回给前端。

### 11.3 可靠性

- AI 返回 JSON 需要服务端校验。
- 部分生成失败时应返回成功数、重复数、失败数。
- 删除建议采用软删除，降低误删风险。

### 11.4 可观测性

- 后端应记录 AI 生成失败原因。
- 后端应记录音频生成失败原因。
- 管理端应显示生成结果摘要。

## 12. 边界情况

- 单词本为空：小程序展示空状态，引导稍后再试。
- 当前难度没有单词：提示该难度暂无内容。
- 没有到期复习词：系统展示未学习新词。
- 没有新词也没有复习词：提示本难度已完成当前练习。
- 单词已下架：不再出现在新的练习队列中，历史进度保留。
- 单词本下架：普通用户不可进入，管理员仍可管理。
- AI 生成数量少于请求数量：显示实际新增数量。
- AI 返回重复单词：跳过重复项或补充来源主题关联。
- 音频文件不存在或 URL 失效：播放失败时提示用户，并允许后台重新生成音频。

## 14. 已确认决策

- 小程序练习形式：先看英文单词，用户点“认识/不认识”，不认识可看详情。
- 掌握规则：连续 4 次复习选择“认识”。
- 复习间隔：1 天、3 天、7 天、15 天。
- 每日学习数量：不限制，用户想学多少学多少。
- 单词本和主题关系：一个单词本可关联多个口语主题，单词记录来源主题。
- 发布规则：AI 生成后可直接发布，支持后续编辑/删除。
- 发音：使用后台可配置 TTS 模型生成美式 + 英式发音，单词和例句音频保存到服务端本地，音频 URL 落库。
- 单词详情不展示 AI 生成批次和排序号。
- AI 提示词：使用内置提示词。
- 去重规则：同一个单词本内英文单词完全相同算重复。
- 后台批量能力：发布、下架、删除、调整排序、重新生成音频。
- 单词练习权限：所有登录用户可用，不再严格要求会员权限。

## 15. 待确认项

- AI 生成是否需要异步任务队列；v1 可以先同步请求，若超时明显再改异步。
- 后台是否需要手动新增单词；本需求建议支持，但用户原始描述重点是 AI 生成。
- 单词例句是否需要支持多个例句；v1 建议先支持一个主例句，后续扩展为 JSON 数组。
