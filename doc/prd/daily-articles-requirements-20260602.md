# 每日外刊模块需求规格

> 日期：2026-06-02
> 状态：待评审
> 适用范围：微信小程序、PC 管理后台、后端 API、MySQL 数据模型、定时任务、文件上传

## 1. 项目概述

### 1.1 产品类型

在现有小柚英语系统中新增“每日外刊”学习模块。功能使用端位于微信小程序：首页和学习中心提供入口，登录用户进入后可以查看每日外刊列表和详情。PC 端只承担管理员后台能力，用于维护外刊库存、音频、正文、翻译、重点词汇、表达句型和文章总结。

### 1.2 一句话目标

为所有登录用户在微信小程序中提供稳定的每日英文外刊阅读入口，让用户通过听音频、读正文、看逐段翻译和学习重点表达完成轻量化英语输入练习。

### 1.3 目标用户

- 普通登录用户：在微信小程序浏览每日外刊列表，阅读详情，查看翻译、词汇、句型和总结。
- 高级用户：与普通登录用户拥有相同的每日外刊权限。
- 管理员：在 PC 管理后台维护外刊库存，并触发每日更新。

### 1.4 平台范围

- 微信小程序：首页入口、学习中心入口、外刊列表页、外刊详情页。
- PC 管理后台：外刊列表、新增、编辑、启用、禁用、音频 URL 或上传、手动触发今日外刊。
- 后端服务：用户端外刊接口、管理端外刊接口、音频上传接口、阅读状态接口、定时发布任务。
- MySQL：新增外刊主表、外刊段落表、用户阅读记录表。

### 1.5 成功定义

- 登录用户能从小程序首页和小程序学习中心进入每日外刊列表。
- 用户能默认看到未读外刊，并在进入详情后自动标记为已读。
- 外刊详情能展示音频、英文正文、逐段中文翻译、文章总结、重点词汇和表达句型。
- 管理员能在 PC 后台维护外刊内容，并选择填写音频 URL 或上传音频文件。
- 系统每天早上 6 点只推送一篇未推送且启用的外刊。
- 当没有可推送外刊时，定时任务正常结束并记录日志，不产生错误数据。

## 2. 产品目标与非目标

### 2.1 目标

- 在微信小程序建立每日外刊阅读模块。
- 在 PC 管理后台建立可维护的外刊内容库。
- 支持文章长文本按段落存储，英文正文和中文翻译一一对应。
- 支持用户按未读和已读筛选外刊。
- 支持进入详情即自动记录用户已读状态。
- 支持音频 URL 和后台上传音频两种音频来源。
- 支持后台启用、禁用和草稿状态，只有启用文章进入每日推送池。
- 支持每日 6 点自动推送一篇未推送外刊。
- 支持管理员手动触发今日外刊推送。

### 2.2 非目标

- v1 不做外部网站抓取、RSS 同步或第三方内容自动导入。
- v1 不做 AI 自动生成外刊正文、翻译、总结、词汇或句型。
- v1 不做阅读进度百分比、阅读时长统计或滚动到页尾才算已读。
- v1 不做收藏、点赞、评论、分享和排行榜。
- v1 不做游客访问。
- v1 不在 PC 用户端新增外刊阅读列表和详情页；PC 只做管理后台。

## 3. 用户角色与权限

### 3.1 游客

- 不能访问每日外刊列表和详情。
- 在小程序首页或学习中心点击入口时，应跳转登录页或展示登录引导。

### 3.2 普通登录用户

- 可以在小程序访问每日外刊列表。
- 可以切换未读和已读 tab。
- 可以进入已推送外刊详情。
- 可以播放音频。
- 可以切换显示或隐藏逐段中文翻译。
- 可以查看文章总结、重点词汇和表达句型。
- 不能访问未推送外刊。
- 不能新增、编辑、启用、禁用或推送外刊。

### 3.3 高级用户

- 每日外刊模块权限与普通登录用户一致。
- 不因高级用户身份获得额外外刊阅读或管理权限。

### 3.4 管理员

- 拥有普通登录用户的所有小程序阅读能力。
- 可以访问 PC 管理后台每日外刊管理页面。
- 可以新增、编辑、启用、禁用外刊。
- 可以填写音频 URL 或上传音频文件。
- 可以查看全部外刊，包括草稿、启用、禁用、未推送和已推送文章。
- 可以手动触发今日外刊推送。

## 4. V1 范围

### 4.1 V1 必须包含

- 小程序首页增加“每日外刊”入口。
- 小程序学习中心增加“每日外刊”入口。
- 小程序新增外刊列表页，默认展示未读外刊。
- 小程序外刊列表支持未读和已读 tab。
- 小程序外刊列表展示英文标题、中文标题和更新日期。
- 小程序外刊列表按更新日期倒序排列。
- 小程序新增外刊详情页。
- 小程序外刊详情页顶部展示音频播放器。
- 小程序外刊详情页展示英文正文。
- 小程序外刊详情页右上方提供中文翻译切换按钮。
- 开启中文翻译后，按段落在英文段落下方展示对应中文翻译。
- 小程序外刊详情页下方展示文章总结、重点词汇和表达句型。
- 进入外刊详情页即记录当前用户已读。
- PC 管理后台新增每日外刊管理入口。
- PC 管理后台支持外刊新增、编辑、启用、禁用。
- PC 管理后台支持音频 URL 和音频文件上传两种方式。
- PC 管理后台支持手动触发今日外刊。
- 后端新增每日 6 点定时推送任务。

### 4.2 后续可选

- 阅读时长、阅读进度和完成状态。
- 收藏、点赞、评论和分享。
- 外刊内容 AI 辅助生成。
- 外部外刊源导入。
- 外刊难度等级和标签筛选。
- 用户阅读历史日历。
- 音频自动 TTS 生成。
- PC 用户端阅读页面。

### 4.3 明确不做

- 不允许游客查看外刊正文。
- 不在数据库中直接保存音频二进制内容。
- 不强制管理员一次性填写所有学习内容字段。
- 不重复推送同一篇外刊。
- 不在已有今日外刊时再次自动推送第二篇。
- 不把每日外刊做成学习中心会员专属功能。

## 5. 核心用户流程

### 5.1 用户从小程序首页进入每日外刊

- 入口：小程序首页“每日外刊”入口。
- 步骤：
  1. 用户点击“每日外刊”入口。
  2. 小程序检查登录状态。
  3. 未登录用户跳转登录页或展示登录引导。
  4. 已登录用户进入外刊列表页。
  5. 列表默认展示未读外刊。
- 成功结果：用户看到按更新日期倒序排列的未读外刊列表。
- 异常路径：
  - 未登录：不进入列表页，提示用户先登录。
  - 列表为空：展示“暂无未读外刊”。
  - 接口失败：展示错误提示和重试按钮。

### 5.2 用户从小程序学习中心进入每日外刊

- 入口：小程序学习中心“每日外刊”入口。
- 步骤：
  1. 用户点击学习中心中的每日外刊入口。
  2. 小程序检查登录状态。
  3. 已登录用户进入外刊列表页。
- 成功结果：用户进入与首页入口相同的每日外刊列表页。
- 异常路径：
  - 未登录：提示登录。
  - 接口失败：展示错误提示和重试按钮。

### 5.3 用户阅读外刊详情

- 入口：小程序外刊列表页的外刊列表项。
- 步骤：
  1. 用户点击一篇外刊。
  2. 小程序进入外刊详情页。
  3. 后端返回外刊详情，并写入当前用户的阅读记录。
  4. 页面顶部展示音频播放器。
  5. 页面展示英文正文段落。
  6. 页面下方展示文章总结、重点词汇和表达句型。
  7. 用户点击右上方“中文翻译”按钮。
  8. 页面在每段英文下方展示对应中文翻译。
- 成功结果：该外刊被标记为已读，并在后续列表中从未读 tab 移入已读 tab。
- 异常路径：
  - 外刊不存在：展示“外刊不存在”。
  - 外刊未推送且用户不是管理员：返回 404 或 403。
  - 音频为空：不展示音频播放器。
  - 音频播放失败：提示“音频暂时无法播放”，正文仍可阅读。
  - 中文翻译缺失：仅展示英文段落。
  - 词汇、句型或总结为空：对应区块不展示。

### 5.4 管理员新增外刊

- 入口：PC 管理后台“每日外刊”管理页面。
- 步骤：
  1. 管理员点击“新增外刊”。
  2. 填写英文标题、中文标题。
  3. 选择音频来源：填写音频 URL 或上传音频文件。
  4. 按段落录入英文正文和中文翻译。
  5. 录入文章总结、重点词汇和表达句型。
  6. 选择保存为草稿、启用或禁用。
  7. 系统保存外刊主信息和段落信息。
- 成功结果：外刊进入后台列表。
- 异常路径：
  - 音频上传失败：提示失败，允许改用 URL 或重新上传。
  - 段落为空：允许保存草稿；启用时建议提示“缺少英文正文”。
  - 表单字段不完整：允许保存，但不完整内容在小程序按空字段规则隐藏。

### 5.5 每日自动推送外刊

- 入口：后端定时任务。
- 执行时间：每天早上 6 点，服务器时区 `Asia/Shanghai`。
- 步骤：
  1. 定时任务启动。
  2. 查询今日是否已有 `publishedDate = today` 的外刊。
  3. 如果今日已有外刊，任务结束。
  4. 查询 `status = ENABLED` 且 `publishedDate IS NULL` 的候选外刊。
  5. 如果候选为空，任务结束并记录日志。
  6. 随机选择一篇候选外刊。
  7. 设置该外刊 `publishedDate = today`。
- 成功结果：小程序用户列表中出现今日外刊。
- 异常路径：
  - 没有候选外刊：不推送，不报错。
  - 数据库更新失败：记录错误日志。
  - 并发触发：只能成功推送一篇，不能重复设置多篇今日外刊。

### 5.6 管理员手动触发今日外刊

- 入口：PC 管理后台每日外刊管理页“生成今日外刊”按钮。
- 步骤：
  1. 管理员点击“生成今日外刊”。
  2. 后端检查今日是否已有外刊。
  3. 今日已有外刊时，返回“今日外刊已存在”。
  4. 今日没有外刊时，执行与定时任务相同的随机选择逻辑。
  5. 选择成功后设置 `publishedDate = today`。
- 成功结果：今日外刊生成，并显示在小程序外刊列表中。
- 异常路径：
  - 没有候选外刊：提示“没有可推送的外刊”。
  - 今日已有外刊：提示“今日外刊已存在”。

## 6. 功能需求

### FR-1 小程序每日外刊入口

- 目标：让用户从小程序首页和学习中心快速进入每日外刊模块。
- 触发：用户点击入口。
- 输入：无。
- 输出：每日外刊列表页或登录引导。
- 业务规则：
  - 未登录用户不能进入外刊列表。
  - 小程序首页和学习中心都必须存在入口。
  - 入口风格应与现有小程序页面设计保持一致。
  - 每日外刊对所有登录用户开放，不受学习中心会员权限限制。
- 权限：所有登录用户可进入。
- 状态：未登录、已登录、加载中、跳转失败。

验收标准：

- [ ] 小程序首页展示每日外刊入口。
- [ ] 小程序学习中心展示每日外刊入口。
- [ ] 未登录用户点击入口会看到登录引导或跳转登录页。
- [ ] 已登录用户点击入口进入每日外刊列表页。
- [ ] 普通登录用户不会被会员权限拦截。

### FR-2 小程序外刊列表

- 目标：让用户按阅读状态浏览已推送外刊。
- 触发：用户进入每日外刊列表页。
- 输入：
  - `status`: `unread` 或 `read`。
  - `page`: 页码。
  - `size`: 每页数量。
- 输出：外刊分页列表。
- 业务规则：
  - 默认 `status = unread`。
  - 只展示 `publishedDate IS NOT NULL` 的外刊。
  - 按 `publishedDate DESC` 排序。
  - 未读为当前用户没有阅读记录的文章。
  - 已读为当前用户存在阅读记录的文章。
  - 支持下拉刷新。
  - 支持触底分页加载。
- 权限：所有登录用户。
- 状态：未读列表、已读列表、空列表、加载中、加载失败、分页加载中、无更多。

验收标准：

- [ ] 默认展示未读 tab。
- [ ] 切换已读 tab 后展示当前用户已读外刊。
- [ ] 列表项展示英文标题、中文标题和更新日期。
- [ ] 列表按更新日期倒序排列。
- [ ] 未读为空时展示空状态。
- [ ] 已读为空时展示空状态。
- [ ] 下拉刷新能重新加载当前 tab。
- [ ] 触底能加载下一页。

### FR-3 小程序外刊详情

- 目标：让用户完整阅读一篇外刊并学习相关内容。
- 触发：用户从列表点击外刊。
- 输入：外刊 ID。
- 输出：外刊详情。
- 业务规则：
  - 进入详情即标记当前用户已读。
  - 音频在页面最上方。
  - 英文正文在音频下方。
  - 文章总结、重点词汇、表达句型在正文下方。
  - 中文翻译默认隐藏。
  - 点击中文翻译按钮后，按段落展示中文翻译。
  - 再次点击按钮可隐藏中文翻译。
  - 音频 URL 如果是 `/uploads/...` 相对路径，小程序需要补全为当前环境下的站点绝对地址。
- 权限：所有登录用户。
- 状态：正常详情、翻译显示、翻译隐藏、音频缺失、学习内容缺失、详情加载失败、音频播放失败。

验收标准：

- [ ] 进入详情页后该文章被记录为已读。
- [ ] 音频播放器显示在正文上方。
- [ ] 英文正文按段落展示。
- [ ] 中文翻译按钮能显示和隐藏逐段翻译。
- [ ] 文章总结、重点词汇、表达句型显示在正文下方。
- [ ] 缺少音频或学习内容时页面不报错。
- [ ] 相对音频 URL 在小程序中能被正确补全播放。

### FR-4 PC 管理后台外刊维护

- 目标：让管理员维护每日外刊库存。
- 触发：管理员进入 PC 每日外刊管理页。
- 输入：英文标题、中文标题、音频 URL 或上传音频、英文正文段落、中文翻译段落、文章总结、重点词汇、表达句型、状态。
- 输出：保存后的外刊。
- 业务规则：
  - 不强制一次性填写所有字段。
  - 草稿允许字段不完整。
  - 启用状态的文章才进入每日推送池。
  - 禁用状态的文章不进入每日推送池。
  - 已推送文章仍可编辑正文、翻译和学习内容。
  - 已推送文章不应被重新推送。
  - 音频 URL 和上传音频二选一即可。
- 权限：仅管理员。

验收标准：

- [ ] 管理员能新增外刊。
- [ ] 管理员能编辑外刊。
- [ ] 管理员能启用和禁用外刊。
- [ ] 管理员能通过 URL 保存音频。
- [ ] 管理员能上传音频并保存上传后的访问地址。
- [ ] 非管理员不能访问管理接口。

### FR-5 每日自动推送

- 目标：每天自动发布一篇未推送外刊。
- 触发：每天早上 6 点定时任务。
- 输入：无。
- 输出：一篇外刊的 `publishedDate` 被设置为当天。
- 业务规则：
  - 使用 `Asia/Shanghai` 时区。
  - 每天最多推送一篇。
  - 今日已有外刊时不再推送。
  - 候选池为 `status = ENABLED` 且 `publishedDate IS NULL` 的文章。
  - 候选池为空时正常结束。
  - 随机选择候选文章。
- 权限：系统内部任务。

验收标准：

- [ ] 每天 6 点执行推送任务。
- [ ] 今日已有外刊时不会重复推送。
- [ ] 禁用和草稿文章不会被选中。
- [ ] 已推送文章不会被再次选中。
- [ ] 无候选文章时任务正常结束。

### FR-6 手动触发今日外刊

- 目标：让管理员在定时任务失败或需要补发时手动生成今日外刊。
- 触发：管理员在 PC 后台点击“生成今日外刊”按钮。
- 输入：无。
- 输出：推送结果。
- 业务规则：
  - 逻辑与每日自动推送一致。
  - 今日已有外刊时返回明确提示，不重复推送。
  - 无候选文章时返回明确提示。
- 权限：仅管理员。

验收标准：

- [ ] 管理员能手动触发今日外刊。
- [ ] 今日已有外刊时提示“今日外刊已存在”。
- [ ] 无候选文章时提示“没有可推送的外刊”。
- [ ] 手动触发不会造成同一天多篇外刊。

## 7. 页面与 UI/UX 要求

### 7.1 小程序视觉方向

- 视觉风格：延续现有小程序首页、学习中心和单词练习模块风格。
- 页面气质：清爽、阅读友好、学习工具型。
- 信息密度：列表页紧凑清晰；详情页强调正文阅读舒适度。
- 交互语气：按钮文案明确，状态反馈及时。
- 移动端要求：适配微信小程序常见手机屏幕，长标题和长句子不能溢出。

### 7.2 页面清单

#### 页面 A：小程序首页入口

- 文件建议：`xiaochengxu/miniprogram/pages/home/*`。
- 目的：提供每日外刊入口。
- 关键信息：模块名称，可选展示今日标题或未读数量。
- 主要操作：点击进入外刊列表。
- 未登录状态：跳转登录页或展示登录引导。

#### 页面 B：小程序学习中心入口

- 文件建议：`xiaochengxu/miniprogram/pages/learning/*`。
- 目的：在学习中心中提供外刊学习入口。
- 关键信息：模块名称。
- 主要操作：点击进入外刊列表。
- 权限要求：只要求登录，不要求会员。

#### 页面 C：小程序外刊列表页

- 页面建议：`pages/dailyArticles/index`。
- 目的：按阅读状态浏览已推送外刊。
- 关键信息：英文标题、中文标题、更新日期。
- 主要操作：点击列表项进入详情。
- 次要操作：切换未读和已读 tab、下拉刷新、触底加载。
- 空状态：
  - 未读为空：显示“暂无未读外刊”。
  - 已读为空：显示“暂无已读外刊”。
- 加载状态：使用现有 loading 组件或页面内加载态。
- 错误状态：显示错误提示和重试按钮。

#### 页面 D：小程序外刊详情页

- 页面建议：`pages/dailyArticleDetail/index`。
- 目的：展示完整外刊内容和学习辅助内容。
- 关键信息：标题、更新日期、音频、英文正文、中文翻译、总结、词汇、句型。
- 主要操作：播放音频、切换中文翻译。
- 次要操作：返回列表。
- 空状态：外刊不存在时展示“外刊不存在”。
- 加载状态：详情页 loading。
- 错误状态：显示错误提示和重试按钮。
- 响应式：正文行宽、行高、段落间距适合手机阅读。

#### 页面 E：PC 管理后台每日外刊列表

- 路由建议：`/admin/daily-articles`。
- 目的：管理员维护外刊库存。
- 关键信息：英文标题、中文标题、状态、是否已推送、更新日期、创建时间。
- 主要操作：新增外刊、编辑外刊、启用、禁用。
- 次要操作：手动触发今日外刊。

#### 页面 F：PC 管理后台外刊编辑

- 目的：创建或编辑外刊内容。
- 关键信息：标题、音频、段落、总结、词汇、句型、状态。
- 主要操作：保存、启用、禁用。
- 次要操作：新增段落、删除段落、调整段落顺序、上传音频。

## 8. 数据模型

### 8.1 `daily_articles`

外刊主表，存储标题、音频、学习内容、状态和推送日期。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | 外刊 ID |
| `title` | VARCHAR(300) | 可空 | 英文标题 |
| `title_zh` | VARCHAR(300) | 可空 | 中文标题 |
| `audio_url` | VARCHAR(1000) | 可空 | 外部音频 URL 或上传后的文件 URL |
| `summary` | TEXT | 可空 | 文章总结 |
| `vocabulary` | JSON | 可空 | 重点词汇 |
| `expressions` | JSON | 可空 | 表达句型 |
| `status` | VARCHAR(20) | NOT NULL | `DRAFT` / `ENABLED` / `DISABLED` |
| `published_date` | DATE | 可空 | 每日更新日期，未推送时为空 |
| `created_at` | DATETIME | NOT NULL | 创建时间 |
| `updated_at` | DATETIME | NOT NULL | 更新时间 |

建议索引：

- `idx_daily_articles_published_date`：`published_date`
- `idx_daily_articles_status_published`：`status, published_date`

### 8.2 `daily_article_paragraphs`

外刊段落表，用于长文本存储和逐段翻译展示。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | 段落 ID |
| `article_id` | BIGINT | FK | 外刊 ID |
| `sort_order` | INT | NOT NULL | 段落顺序，从 1 开始 |
| `content_en` | TEXT | 可空 | 英文段落 |
| `content_zh` | TEXT | 可空 | 中文翻译段落 |

建议索引：

- `idx_daily_article_paragraphs_article_order`：`article_id, sort_order`

### 8.3 `daily_article_reads`

用户阅读记录表。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| `id` | BIGINT | PK, AUTO_INCREMENT | 阅读记录 ID |
| `article_id` | BIGINT | FK | 外刊 ID |
| `user_id` | BIGINT | FK | 用户 ID |
| `read_at` | DATETIME | NOT NULL | 首次阅读时间 |

约束和索引：

- 唯一约束：`uk_daily_article_reads_article_user`：`article_id, user_id`
- 索引：`idx_daily_article_reads_user`：`user_id`

业务规则：

- 用户进入详情页时写入阅读记录。
- 如果记录已存在，不重复插入，可保持原 `read_at`。

### 8.4 JSON 字段格式

`vocabulary` 建议格式：

```json
[
  {
    "word": "resilience",
    "zh": "韧性",
    "explanation": "ability to recover quickly after difficulty",
    "example": "Resilience matters in difficult times."
  }
]
```

`expressions` 建议格式：

```json
[
  {
    "expression": "shed light on",
    "zh": "阐明，使人了解",
    "example": "The report sheds light on the issue."
  }
]
```

建议查询参数：

权限：管理员。

请求体：同新增外刊。

更新外刊状态。

权限：管理员。

```json

  "status": "ENABLED"
}
```

上传外刊音频文件。

权限：管理员。

字段：

- `file`: 音频文件。

响应：


## 10. 定时任务要求

### 10.1 执行时间

- Cron：`0 0 6 * * *`
- 时区：`Asia/Shanghai`
- 频率：每天一次。

### 10.2 任务逻辑

1. 获取当前日期 `today`。
2. 查询是否存在 `publishedDate = today` 的外刊。
3. 如果存在，记录日志并结束。
4. 查询候选外刊：
   - `status = ENABLED`
   - `publishedDate IS NULL`
5. 如果候选为空，记录日志并结束。
6. 随机选择一篇候选外刊。
7. 将该外刊 `publishedDate` 设置为 `today`。
8. 保存并记录日志。

### 10.3 幂等与并发

- 定时任务和手动触发必须复用同一个服务方法。
- 服务方法需要事务保护。
- 写入前再次检查今日是否已有外刊。
- 应避免并发情况下同一天发布多篇文章。

## 11. 技术约束

- 小程序沿用原生 WXML/WXSS/JS，通过 `xiaochengxu/miniprogram/utils/api.js` 和 `utils/request.js` 调用后端 REST API。
- PC 管理后台沿用 Next.js 14、React、TypeScript、Tailwind CSS、TanStack React Query。
- 后端沿用 Spring Boot 3.2.5、Spring Security、Spring Data JPA、MySQL。
- 认证沿用现有 JWT。
- 文件上传复用或扩展现有 `uploads` 目录策略。
- 数据库长文本正文不直接塞入主表大 JSON，正文和翻译按段落拆表存储。
- 音频文件不以 BLOB 形式存储到数据库，数据库只保存可访问 URL。
- 小程序用户列表接口只返回已推送外刊。
- 小程序播放相对音频 URL 时，需要基于当前环境后端站点补全绝对地址。

## 12. 非功能需求

### 12.1 性能

- 外刊列表接口应分页。
- 小程序列表页支持分页加载，避免一次性加载全部外刊。
- 外刊详情一次返回主信息、段落、词汇、句型和阅读状态。
- 段落按 `article_id, sort_order` 建索引。

### 12.2 安全

- 用户端接口必须要求登录。
- 管理端接口必须要求 `ROLE_ADMIN`。
- 音频上传接口必须限制文件类型和文件大小。
- 上传文件名不得直接信任用户原始文件名，应生成安全文件名。
- 普通用户不能访问未推送外刊详情。

### 12.3 可靠性

- 定时任务失败必须记录日志。
- 无候选外刊不算失败。
- 今日已有外刊不算失败。
- 手动触发和定时任务应避免重复发布。

### 12.4 可维护性

- 推送逻辑应集中在后端 service 中，定时任务和管理接口复用。
- 段落保存应支持整体替换，避免部分更新导致顺序错乱。
- 阅读记录写入应使用唯一约束或幂等逻辑。
- 小程序接口封装应放在 `xiaochengxu/miniprogram/utils/api.js`，页面不直接拼接 REST 请求。

## 15. 假设

- 上传音频保存到后端本地上传目录或后续可替换为对象存储，数据库只保存 URL。
- 管理员录入内容不做强制完整校验，但启用时可以给出缺少关键内容的提示。
- 英文正文和中文翻译按段落一一对应。
- 进入详情页即算已读，不要求停留时间或滚动进度。
- 外刊列表仅展示已推送文章。
- 每天最多一篇每日外刊。
- 小程序当前通过 `utils/request.js` 直连 Spring Boot REST API，不通过云函数实现每日外刊业务。

## 16. 开放问题

- PC 后台是否需要支持删除外刊。当前需求只明确新增、编辑、启用、禁用，v1 可先不提供硬删除。
- 音频上传的最大文件大小需要最终确定，建议先限制为 50 MB。
- 外刊详情是否需要展示标签或难度等级，当前 v1 不包含。
- 小程序首页入口是否展示今日外刊标题或未读数量，当前可作为可选增强。
