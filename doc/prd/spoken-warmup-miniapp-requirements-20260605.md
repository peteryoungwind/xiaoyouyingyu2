# 微信小程序口语热身模块需求规格

> 日期：2026-06-05
> 状态：待评审
> 适用范围：微信小程序、后端 API、AI 默认模型配置

## 1. 项目摘要

### 1.1 产品类型

在现有小柚英语微信小程序中新增“口语热身”学习模块。该模块替换首页当前未实现的“听力练习”入口，面向所有已登录用户开放。用户基于系统已有主题选择初级或进阶水平后，可以自由进入热身介绍、核心词汇、句型模板、地道表达、模拟问答任务和 AI 点评等模块。

### 1.2 一句话目标

让登录用户围绕已有英语主题，通过 AI 实时生成的分级学习资料完成一次轻量但完整的口语开口前热身练习。

### 1.3 目标用户

- 普通登录用户：可以在小程序中使用口语热身完整功能。
- 高级用户：与普通登录用户拥有相同的口语热身权限。
- 管理员：拥有普通用户能力；后台继续维护主题和默认 AI 模型配置。

### 1.4 平台范围

- 微信小程序：首页入口、口语热身主题列表页、口语热身主题详情页。
- 后端服务：复用现有主题接口和学习中心 AI 接口，并必须补齐或复用真实语音转文字能力；句型模板、地道表达按本需求补齐。
- AI 模型：使用后台已配置的默认模型；小程序端不提供模型选择。
- 数据库：V1 不新增口语热身学习记录表，不保存 AI 生成内容，不保存录音文件。

### 1.5 成功定义

- 登录用户能从小程序首页点击“口语热身”进入主题列表。
- 用户能按关键词、标签、日期筛选系统已有主题。
- 用户能选择初级或进阶水平，并自由打开任意学习模块。
- 每个模块在用户点击时独立实时生成内容。
- 用户能在模拟练习中默认使用语音输入，也可以切换为文字输入。
- 用户提交英文回答后，AI 能返回评分、纠错、优化表达和鼓励。

## 2. 产品目标与非目标

### 2.1 目标

- 将小程序首页“听力练习”入口替换为“口语热身”。
- 复用系统已有主题作为练习主题来源。
- 支持主题关键词搜索、标签筛选和日期筛选。
- 支持初级和进阶两个水平。
- 支持热身介绍、核心词汇、句型模板、地道表达、模拟问答任务和 AI 点评。
- 支持每个模块按需实时生成，而不是进入页面后一次性生成全部内容。
- 支持每个模块重新生成，并在本次页面会话内通过 `exclude` 避免重复内容。
- 模拟练习同时支持语音输入和文字输入，默认展示语音输入。
- 使用后台配置的默认 AI 模型生成全部学习资料和点评。

### 2.2 非目标

- V1 不保存 AI 生成内容到数据库。
- V1 不保存用户学习进度。
- V1 不提供历史记录回看。
- V1 不保存用户录音文件。
- V1 不做发音评分、流利度评分或音素级纠音。
- V1 不做实时语音通话。
- V1 不新增会员权限限制；所有已登录用户权限一致。
- V1 不在 PC 前端新增用户侧口语热身页面。

## 3. 目标用户与角色

### 3.1 游客

- 不能使用口语热身模块。
- 在首页点击“口语热身”入口时，应进入现有登录引导。

### 3.2 普通登录用户

- 可以进入口语热身主题列表。
- 可以搜索、标签筛选和日期筛选主题。
- 可以选择任意主题进入口语热身详情页。
- 可以切换初级和进阶水平。
- 可以自由生成和重新生成各学习模块内容。
- 可以通过语音或文字输入模拟练习回答。
- 可以提交回答并查看 AI 点评。

### 3.3 高级用户

- 口语热身模块权限与普通登录用户一致。
- 不因高级用户身份获得额外生成次数或额外内容。

### 3.4 管理员

- 拥有普通登录用户的全部小程序能力。
- 可以继续通过现有后台维护主题和默认 AI 模型。
- V1 不需要新增专门的口语热身管理后台。

## 4. V1 范围

### 4.1 V1 必须包含

- 小程序首页入口替换：将“听力练习”改为“口语热身”。
- 口语热身主题列表页。
- 主题列表复用现有主题数据。
- 主题列表支持关键词搜索、标签筛选、日期筛选。
- 主题详情页展示主题英文标题、中文标题、日期、标签。
- 主题详情页支持初级/进阶切换，默认初级。
- 热身介绍模块：生成 1 段介绍和 3 个热身问题。
- 核心词汇模块：生成 10 个核心词汇。
- 句型模板模块：生成 6 个句型模板。
- 地道表达模块：生成 6 个地道表达。
- 模拟问答任务模块：生成 3 个模拟任务。
- AI 点评模块：用户提交回答后生成 1 份点评。
- 每个模块点击时分别实时生成。
- 每个模块支持重新生成。
- 重新生成时，本次进入页面已经生成过的内容不能重复生成。
- 模拟练习支持语音输入和文字输入，默认语音输入。
- 语音输入必须完成真实语音转文字：小程序录制真实音频并调用 ASR 能力返回识别文本，不能只录音后提示用户手动填写。

### 4.2 后续可选

- 学习记录、历史回看和进度统计。
- 发音评分、流利度评分和语音波形反馈。
- 收藏词汇、句型和表达。
- 将生成内容一键加入单词本或错题本。
- 按会员等级限制每日生成次数。
- 口语热身结果分享。
- 离线缓存最近一次生成结果。

### 4.3 明确排除

- 不允许游客查看完整口语热身内容。
- 不新增付费逻辑。
- 不保存每次 AI 生成内容。
- 不保存用户语音文件。
- 不要求 AI 内容跨页面、跨设备或跨用户去重。
- 不把“听力练习”旧入口保留为并列入口。

## 5. 核心用户流程

### 5.1 从首页进入口语热身

- 入口：小程序首页“口语热身”入口。
- 步骤：
  1. 用户打开小程序首页。
  2. 用户点击“口语热身”。
  3. 小程序检查登录状态。
  4. 未登录用户跳转登录页或展示登录引导。
  5. 已登录用户进入口语热身主题列表页。
- 成功结果：用户看到可搜索和筛选的主题列表。
- 异常路径：
  - 未登录：不进入主题列表，提示先登录。
  - 主题接口失败：展示错误提示和重试按钮。

### 5.2 搜索和筛选主题

- 入口：口语热身主题列表页。
- 步骤：
  1. 用户输入关键词。
  2. 用户可选择标签。
  3. 用户可选择日期范围。
  4. 小程序调用现有主题列表接口。
  5. 页面展示匹配的主题。
  6. 用户点击主题进入详情页。
- 成功结果：用户进入所选主题的口语热身详情页。
- 异常路径：
  - 无匹配主题：展示“暂无匹配主题”。
  - 网络失败：展示“加载失败，点击重试”。

### 5.3 选择水平并自由生成模块

- 入口：口语热身主题详情页。
- 步骤：
  1. 页面展示主题信息。
  2. 默认选择初级。
  3. 用户可以切换到进阶。
  4. 用户点击任意模块，例如核心词汇。
  5. 小程序调用对应 AI 接口。
  6. 页面展示生成内容。
  7. 用户可以继续点击其他模块。
- 成功结果：用户按自己的节奏完成各部分热身。
- 异常路径：
  - 默认模型缺失：提示“AI 生成暂不可用，请稍后再试”。
  - AI 生成失败：当前模块展示错误和重试按钮，不影响其他模块。

### 5.4 重新生成并避免本次重复

- 入口：任意已生成内容模块。
- 步骤：
  1. 用户点击“重新生成”。
  2. 小程序收集本次页面会话中该模块已生成内容。
  3. 小程序将已生成内容作为 `exclude` 参数传给后端。
  4. 后端 Prompt 要求 AI 避免生成 `exclude` 中已出现的内容。
  5. 页面展示新生成内容。
- 成功结果：新内容与本次已生成内容不重复或明显不同。
- 异常路径：
  - AI 仍返回重复内容：页面正常展示，不崩溃；可提示用户再次重新生成。
  - 重新生成失败：保留旧内容，并展示错误提示。

### 5.5 模拟练习使用语音输入

- 入口：模拟问答任务模块。
- 步骤：
  1. 用户生成 3 个模拟任务。
  2. 用户选择一个任务。
  3. 回答区默认展示语音输入模式。
  4. 用户点击或长按录音按钮开始录音。
  5. 小程序完成语音识别，将语音转为文本。
  6. 页面展示识别出的英文文本。
  7. 用户可编辑识别文本。
  8. 用户点击“提交点评”。
  9. 后端调用 AI 点评接口。
  10. 页面展示 AI 点评。
- 成功结果：用户通过语音回答并获得一份结构化点评。
- 异常路径：
  - 录音权限未授权：展示授权引导，并允许切换文字输入。
  - 语音识别失败：提示重试，并允许切换文字输入。
  - 识别结果为空：不能提交点评。

### 5.6 模拟练习使用文字输入

- 入口：模拟问答任务模块回答区。
- 步骤：
  1. 用户点击“文字输入”切换。
  2. 用户输入英文回答。
  3. 用户点击“提交点评”。
  4. 后端调用 AI 点评接口。
  5. 页面展示 AI 点评。
- 成功结果：用户通过文字回答并获得一份结构化点评。
- 异常路径：
  - 回答为空：提交按钮禁用。
  - AI 点评失败：展示错误和重试按钮。

## 6. 功能需求

### FR-1 首页入口替换

- 目标：让用户从首页进入口语热身模块。
- 触发：用户点击首页学习入口区的“口语热身”。
- 输入：无。
- 输出：进入口语热身主题列表页或登录引导。
- 业务规则：
  - 替换当前“听力练习”入口。
  - 不保留“听力练习”并列入口。
  - 入口图标和样式延续当前首页学习入口视觉。
  - 未登录用户不能进入主题列表。
- 权限：已登录用户可用。
- 状态：正常、未登录、跳转中。

验收标准：

- [ ] 首页不再展示“听力练习”入口。
- [ ] 首页展示“口语热身”入口。
- [ ] 未登录点击入口会进入登录引导。
- [ ] 已登录点击入口会进入口语热身主题列表页。

### FR-2 口语热身主题列表

- 目标：让用户从系统已有主题中选择一个热身主题。
- 触发：用户进入口语热身主题列表页。
- 输入：
  - `keyword`：关键词，可为空。
  - `tag`：标签，可为空。
  - `startDate`：开始日期，可为空。
  - `endDate`：结束日期，可为空。
  - `page`、`size`：分页参数。
- 输出：主题分页列表。
- 业务规则：
  - 主题数据直接复用现有主题列表接口。
  - 关键词搜索应匹配英文标题、中文标题和问题内容。
  - 标签筛选和日期筛选可以与关键词组合使用。
  - 列表项至少展示英文标题、中文标题、标签和日期。
  - 支持下拉刷新和触底加载更多。
- 权限：已登录用户。
- 状态：加载中、加载成功、空结果、加载失败、加载更多中、无更多数据。

验收标准：

- [ ] 用户可以看到系统已有主题列表。
- [ ] 用户可以按关键词搜索主题。
- [ ] 用户可以按标签筛选主题。
- [ ] 用户可以按日期范围筛选主题。
- [ ] 用户点击主题后进入对应口语热身详情页。
- [ ] 空结果展示明确空状态。
- [ ] 加载失败展示重试入口。

### FR-3 主题详情和水平切换

- 目标：让用户基于一个主题选择适合的口语热身水平。
- 触发：用户点击主题列表中的主题。
- 输入：主题 ID。
- 输出：口语热身详情页。
- 业务规则：
  - 页面顶部展示主题英文标题、中文标题、日期和标签。
  - 默认水平为初级。
  - 用户可以在初级和进阶之间切换。
  - 切换水平后，不得混用另一水平已经生成的内容。
  - 推荐按水平分别维护当前页面内存缓存；也可以在切换水平时清空当前展示内容。
- 权限：已登录用户。
- 状态：主题加载中、主题不存在、主题加载失败、正常展示。

水平差异：

- 初级：
  - 词汇偏常用和场景必备。
  - 句型更短，结构更清晰。
  - 问题更具体。
  - 中文辅助更多。
  - 点评更鼓励，重点指出关键错误。
- 进阶：
  - 词汇更地道，包含搭配和表达层次。
  - 句型更复杂，鼓励从句、转折和让步表达。
  - 问题更开放，更强调观点和论证。
  - 中文辅助更少。
  - 点评更严格，关注准确性、逻辑、自然度和表达升级。

验收标准：

- [ ] 页面显示当前主题基本信息。
- [ ] 默认选中初级。
- [ ] 用户可以切换初级和进阶。
- [ ] 切换水平后不会展示错误水平的生成内容。
- [ ] 初级和进阶生成内容在难度上有可感知差异。

### FR-4 热身介绍模块

- 目标：帮助用户快速进入主题语境。
- 触发：用户点击“热身介绍”模块的生成按钮，或首次展开该模块。
- 输入：
  - `titleEn`
  - `titleZh`
  - `mode`：`beginner` 或 `advanced`
  - `exclude`：本次页面会话中已生成的热身介绍和问题，可为空
- 输出：
  - `introduction`：1 段英文或中英结合介绍。
  - `warmupQuestions`：3 个热身问题，每个包含英文和中文。
- 业务规则：
  - 初级介绍可包含更多中文解释。
  - 进阶介绍应更偏英文语境输入。
  - 重新生成时应避免重复之前的问题角度。
- 权限：已登录用户。
- 状态：未生成、生成中、生成成功、生成失败。

验收标准：

- [ ] 点击热身介绍后才调用 AI 接口。
- [ ] 成功后展示 1 段介绍和 3 个热身问题。
- [ ] 重新生成时请求体包含 `exclude`。
- [ ] 生成失败时展示重试按钮。

### FR-5 核心词汇模块

- 目标：提供本主题开口前需要掌握的核心词汇。
- 触发：用户点击“核心词汇”模块的生成按钮，或首次展开该模块。
- 输入：
  - `titleEn`
  - `titleZh`
  - `mode`
  - `exclude`
- 输出：10 个词汇项。
- 单个词汇项建议字段：
  - `word`：英文词或短语。
  - `zh`：中文释义。
  - `example`：英文例句。
  - `exampleZh`：例句中文解释。
  - `category`：分类，如观点、情绪、行为、场景。
  - `difficulty`：`basic`、`intermediate` 或 `advanced`。
- 业务规则：
  - 初级避免过难词汇，但也不应只生成过于基础的单词。
  - 进阶应包含搭配、短语动词或更自然的表达。
  - 重新生成时避免重复已生成词汇和近义替换过低的内容。
- 权限：已登录用户。
- 状态：未生成、生成中、生成成功、生成失败。

验收标准：

- [ ] 点击核心词汇后才调用 AI 接口。
- [ ] 每次成功生成 10 个词汇项。
- [ ] 每个词汇项包含释义和例句。
- [ ] 重新生成时尽量不重复本次已生成词汇。

### FR-6 句型模板模块

- 目标：提供可直接套用的口语句型框架。
- 触发：用户点击“句型模板”模块的生成按钮，或首次展开该模块。
- 输入：
  - `titleEn`
  - `titleZh`
  - `mode`
  - `exclude`
- 输出：6 个句型模板。
- 单个句型模板建议字段：
  - `pattern`：英文句型模板。
  - `zh`：中文解释。
  - `useCase`：适用场景。
  - `example`：套用主题后的英文例句。
  - `exampleZh`：例句中文解释。
- 业务规则：
  - 初级句型应短、清晰、容易替换关键词。
  - 进阶句型应包含更复杂逻辑关系，如原因、转折、让步、比较、假设。
  - 重新生成时避免重复模板结构。
- 权限：已登录用户。
- 状态：未生成、生成中、生成成功、生成失败。

验收标准：

- [ ] 点击句型模板后才调用 AI 接口。
- [ ] 每次成功生成 6 个句型模板。
- [ ] 每个模板包含中文解释、使用场景和例句。
- [ ] 重新生成时尽量不重复本次已生成模板。

### FR-7 地道表达模块

- 目标：提供能提升自然度的主题相关表达。
- 触发：用户点击“地道表达”模块的生成按钮，或首次展开该模块。
- 输入：
  - `titleEn`
  - `titleZh`
  - `mode`
  - `exclude`
- 输出：6 个地道表达。
- 单个表达建议字段：
  - `expression`：英文表达。
  - `zh`：中文含义。
  - `usage`：使用说明。
  - `example`：英文例句。
  - `exampleZh`：例句中文解释。
- 业务规则：
  - 初级表达应常用、低风险、容易开口。
  - 进阶表达应更自然，可包含固定搭配、语气表达或观点表达。
  - 避免生成不适合口语场景的书面化表达。
  - 重新生成时避免重复已生成表达。
- 权限：已登录用户。
- 状态：未生成、生成中、生成成功、生成失败。

验收标准：

- [ ] 点击地道表达后才调用 AI 接口。
- [ ] 每次成功生成 6 个表达。
- [ ] 每个表达包含含义、使用说明和例句。
- [ ] 重新生成时尽量不重复本次已生成表达。

### FR-8 模拟问答任务模块

- 目标：让用户基于主题完成可开口的模拟回答。
- 触发：用户点击“模拟问答”模块的生成按钮，或首次展开该模块。
- 输入：
  - `titleEn`
  - `titleZh`
  - `mode`
  - `exclude`
- 输出：3 个模拟任务。
- 单个任务建议字段：
  - `id`：前端本地生成或后端返回的临时 ID。
  - `title`：英文任务标题。
  - `titleZh`：中文任务标题。
  - `prompt`：英文问题或任务说明。
  - `promptZh`：中文说明。
  - `type`：如 `short_answer`、`opinion`、`role_play`。
  - `difficulty`：`easy`、`medium`、`hard`。
  - `suggestedLength`：建议回答长度，如 `30-60 seconds` 或 `3-5 sentences`。
- 业务规则：
  - 初级任务应具体，允许更多中文辅助。
  - 进阶任务应更开放，鼓励观点展开和理由说明。
  - 重新生成时避免重复任务问题和练习角度。
- 权限：已登录用户。
- 状态：未生成、生成中、生成成功、生成失败。

验收标准：

- [ ] 点击模拟问答后才调用 AI 接口。
- [ ] 每次成功生成 3 个任务。
- [ ] 用户可以选择任意任务进行回答。
- [ ] 重新生成时尽量不重复本次已生成任务。

### FR-9 模拟练习输入

- 目标：让用户用语音或文字提交英文回答，其中语音输入为默认方式。
- 触发：用户在模拟问答任务中选择一个任务。
- 输入方式：
  - `voice`：语音输入，默认。
  - `text`：文字输入，用户手动切换。
- 语音输入业务规则：
  - 回答区默认展示语音输入控件。
  - 用户点击或长按录音按钮开始录音，具体交互遵循当前小程序已有录音模式。
  - 录音结束后应进行语音转文字。
  - 识别结果展示在页面上，用户可以编辑后提交。
  - 语音识别失败时，应允许用户重录或切换到文字输入。
  - 录音权限未授权时，应展示授权引导。
  - 不保存录音文件。
- 文字输入业务规则：
  - 用户切换到文字输入后，展示多行文本输入框。
  - 用户可以输入英文或中英混合内容，但 AI 点评应鼓励使用英文回答。
  - 空文本不能提交。
- 权限：已登录用户。
- 状态：默认语音、录音中、识别中、识别成功、识别失败、文字输入、待提交。

验收标准：

- [ ] 模拟练习回答区默认是语音输入。
- [ ] 用户可以切换到文字输入。
- [ ] 语音输入完成后能得到可编辑的文本。
- [ ] 录音权限失败时有明确提示。
- [ ] 语音识别失败时可重试或改用文字。
- [ ] 空回答不能提交 AI 点评。

### FR-10 AI 点评

- 目标：对用户模拟回答给出可执行的口语改进反馈。
- 触发：用户点击“提交点评”。
- 输入：
  - `titleEn`
  - `titleZh`
  - `mode`
  - `taskTitle`
  - `taskDescription`
  - `answer`：语音识别文本或文字输入内容
- 输出：
  - `score`：0-100 分。
  - `strengths`：优点列表。
  - `improvements`：改进建议列表。
  - `corrections`：错误纠正列表。
  - `improvedAnswer`：优化后的参考回答。
  - `encouragement`：鼓励语。
- 单个纠错项建议字段：
  - `original`：原句。
  - `corrected`：修改后句子。
  - `explanationZh`：中文解释。
- 业务规则：
  - 初级点评更易懂、更鼓励，重点指出影响表达的关键错误。
  - 进阶点评更严格，关注语法准确性、逻辑展开、自然度和表达升级。
  - 点评基于最终提交文本，不直接分析语音音频。
  - 同一任务可以多次提交点评；V1 不保存历史点评。
- 权限：已登录用户。
- 状态：待提交、点评中、点评成功、点评失败。

验收标准：

- [ ] 用户提交回答后生成 1 份点评。
- [ ] 点评包含评分、优点、改进建议、纠错、优化回答和鼓励语。
- [ ] 点评失败时展示错误和重试按钮。
- [ ] 初级和进阶点评风格符合难度差异。

## 7. 接口与集成要求

### 7.1 主题列表接口

复用现有接口：

```http
GET /api/topics
```

查询参数：

- `page`
- `size`
- `keyword`
- `tag`
- `startDate`
- `endDate`

小程序端要求：

- 登录用户可以使用搜索和筛选。
- 请求失败时展示重试。
- 列表字段不足时，应优先补齐小程序展示需要的标题、中文标题、标签和日期。

### 7.2 AI 学习内容接口

优先复用现有学习中心接口：

```http
POST /api/learning/warmup
POST /api/learning/vocabulary
POST /api/learning/expressions
POST /api/learning/tasks
POST /api/learning/review
```

建议补齐或明确拆分：

```http
POST /api/learning/sentence-patterns
POST /api/learning/idiomatic-expressions
```

如果不新增接口，也可以让 `POST /api/learning/expressions` 支持 `type` 参数：

```json
{
  "titleEn": "Travel Experiences",
  "titleZh": "旅行经历",
  "mode": "beginner",
  "type": "sentencePatterns",
  "exclude": "..."
}
```

或：

```json
{
  "titleEn": "Travel Experiences",
  "titleZh": "旅行经历",
  "mode": "beginner",
  "type": "idiomaticExpressions",
  "exclude": "..."
}
```

通用规则：

- 所有生成接口必须要求登录。
- 所有生成接口使用后台配置的默认 AI 模型。
- 小程序端不传 `modelId`。
- 默认模型不存在、禁用或配置不完整时，后端返回明确错误。
- `exclude` 用于本次页面会话内去重，不落库。
- AI 返回应尽量是可解析 JSON；解析失败时返回可读错误。

### 7.3 语音转文字接口

语音转文字是 V1 必做能力。口语热身可以复用现有 AI 对话模块的 ASR 能力，但必须满足“录制真实音频文件 → 上传或传给识别能力 → 返回识别文本”的完整链路。如果现有 AI 对话模块只有录音 UI、没有真实转写，则不得视为满足要求。

若现有后端没有可复用的真实 ASR 接口，必须新增：

```http
POST /api/learning/speech-to-text
Content-Type: multipart/form-data
```

请求：

- `audioFile`：用户本次录音文件。
- `topicId`：可选，用于日志或上下文。
- `mode`：`beginner` 或 `advanced`，可选。

响应：

```json
{
  "text": "I think traveling helps me learn about different cultures."
}
```

业务规则：

- 接口要求登录。
- 录音文件仅用于本次识别，不保存为学习资料。
- 识别失败应返回明确错误。
- 小程序拿到识别文本后，仍调用 `POST /api/learning/review` 完成点评。
- 语音识别结果必须来自用户本次录音，不允许用固定文案、空文本、手动输入占位或“录音完成，请编辑文本”替代真实转写。
- 识别文本返回后必须展示给用户确认和编辑，用户确认后的文本才进入 AI 点评。
- 若 ASR 服务暂不可用，语音输入应显示失败状态，并允许重录或切换文字输入；不能静默降级为假识别。

## 9. 数据模型

### 9.1 数据库存储

V1 不新增数据库表。

不保存：

- AI 生成的热身介绍。
- AI 生成的词汇、句型、表达、任务。
- 用户语音文件。
- 用户文字回答。
- AI 点评结果。
- 学习进度。

### 9.2 前端页面会话状态

建议在小程序页面内存中维护当前主题、当前难度和已生成内容。

```ts
type WarmupLevel = 'beginner' | 'advanced'

type WarmupInputMode = 'voice' | 'text'

type GeneratedCacheByLevel = {
  beginner?: GeneratedCache
  advanced?: GeneratedCache
}

type GeneratedCache = {
  warmup?: WarmupContent[]
  vocabulary?: VocabularyItem[][]
  sentencePatterns?: SentencePattern[][]
  idiomaticExpressions?: ExpressionItem[][]
  tasks?: SpeakingTask[][]
  reviewsByTaskLocalId?: Record<string, ReviewResult>
}

type WarmupContent = {
  introduction: string
  warmupQuestions: Array<{ en: string; zh: string }>
}

type VocabularyItem = {
  word: string
  zh: string
  example: string
  exampleZh?: string
  category?: string
  difficulty?: string
}

type SentencePattern = {
  pattern: string
  zh: string
  useCase?: string
  example: string
  exampleZh?: string
}

type ExpressionItem = {
  expression: string
  zh: string
  usage?: string
  example: string
  exampleZh?: string
}

type SpeakingTask = {
  id: string
  title: string
  titleZh?: string
  prompt: string
  promptZh?: string
  type?: string
  difficulty?: string
  suggestedLength?: string
}

type ReviewResult = {
  score: number
  strengths: string[]
  improvements: string[]
  corrections: Array<{
    original: string
    corrected: string
    explanationZh: string
  }>
  improvedAnswer: string
  encouragement: string
}
```

说明：

- 数组的二维结构用于保留本次页面会话中多次生成的批次，便于重新生成时组装 `exclude`。
- 页面退出后这些数据可以丢失。
- 如果实现成本更低，也可以只保留扁平数组和最近一次展示内容，但必须能构造本次已生成内容的 `exclude`。

## 10. AI Prompt 与生成规则

### 10.1 通用规则

- AI 必须围绕当前主题生成内容。
- AI 必须遵守当前水平：初级或进阶。
- AI 必须返回结构化 JSON。
- AI 不应输出 Markdown 包裹符。
- AI 生成内容应适合英语口语练习，不应过度书面化。
- 当请求中包含 `exclude` 时，AI 必须避免生成其中已出现的词汇、句型、表达、问题、任务和角度。

### 10.2 默认模型规则

- 所有口语热身 AI 请求使用后台配置的默认模型。
- 默认模型从现有 `ai_models` 配置中读取。
- 小程序端不展示模型名称、API Key 或模型选择器。
- 默认模型不可用时，不应回退到硬编码 API Key。

### 10.3 JSON 解析规则

- 后端应尽量清洗 AI 返回内容，解析出 JSON。
- JSON 解析失败时，后端返回明确错误，例如“AI 返回格式异常，请重试”。
- 前端收到格式异常时展示重试，不应白屏。

## 11. 非功能需求

- 性能：
  - 主题列表首屏加载应在正常网络下 3 秒内完成。
  - AI 生成单模块超时时间建议不少于 60 秒。
  - 每个模块独立 loading，避免整页阻塞。
- 安全：
  - 所有口语热身生成和点评接口要求登录。
  - 前端不暴露 AI API Key。
  - 录音文件不落库保存。
- 可靠性：
  - AI 失败、语音识别失败、网络失败时均提供重试或替代输入方式。
  - 某个模块失败不影响其他模块使用。
- 隐私：
  - 用户语音仅用于本次转写。
  - 用户回答和点评 V1 不持久化。
- 兼容性：
  - 适配微信小程序常见 iOS 和 Android 机型。
  - 录音权限被拒绝时，文字输入必须可用。
- 可访问性：
  - 按钮文字清晰。
  - 录音、识别、生成中状态有明确反馈。
  - 中英文长文本自动换行。

## 12. 异常与边界情况

- 未登录点击入口：进入登录引导。
- 主题列表为空：展示空状态。
- 搜索无结果：展示“暂无匹配主题”。
- 主题不存在或被删除：展示“主题不存在或已下架”。
- 默认 AI 模型缺失：展示“AI 生成暂不可用，请稍后再试”。
- AI 返回空内容：展示重试按钮。
- AI 返回非 JSON：展示格式异常和重试按钮。
- 重新生成返回重复内容：页面不崩溃，允许再次重新生成。
- 切换难度：不得展示另一难度的旧内容。
- 录音权限未授权：提示授权并提供文字输入。
- 语音识别失败：允许重录或切换文字输入。
- 用户回答为空：提交点评按钮禁用。
- 用户回答过长：建议前端限制字数或提示缩短，避免 AI 请求过大。
