每日外刊精读升级

把现有「每日外刊」详情升级为对标公众号外刊精读的沉浸式阅读：文章元信息（难度星级 / 字数 / 来源）、迷你音频播放器（播放暂停 / 进度拖动 / 倍速含 2.0）、逐段点击查看翻译 + 顶部一键全显、带英美音标和词性的重点词汇、长难句解析。视觉延续系统蓝色主题：浅灰背景、白色高圆角卡片、蓝色主操作 #007AFF、轻量阴影。

FR-1 布局升级 FR-2 元信息条 FR-3 逐段翻译 FR-4 迷你播放器 FR-5 词汇音标词性 FR-6 长难句解析

建议评审顺序

  1. 先看列表页，确认封面露出、入口与卡片密度。
  2. 再看精读详情默认态，确认六大模块顺序与元信息条。
  3. 看翻译全显态，确认逐段与全局开关协同。
  4. 看播放器交互态，确认倍速面板与拖动反馈。
  5. 最后看加载 / 错误状态。
01

外刊列表 · 封面卡片

未读 / 已读 tab、文章封面、英文标题与中文标题入口，用于交代精读详情的来路。
02

精读详情 · 默认态

英雄标题 + 元信息条 + 迷你播放器 + 中英正文（默认仅英文 + 逐段查看翻译）+ 总结 + 词汇 + 长难句 + 表达。
03

精读详情 · 播放与全文翻译态

顶部一键全显中文后，逐段译文展开；同时展示播放中状态与倍速面板。
04

学习模块 · 词汇 / 长难句 / 表达

聚焦详情页下半部分：重点词汇、长难句解析、表达句型的内容密度与卡片样式。
05

加载 / 错误状态

详情骨架屏加载态与「外刊不存在 + 重试」错误态，覆盖关键异常路径。
