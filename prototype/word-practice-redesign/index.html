Xiaoyou English Mini Program

单词练习入口与 UI 重构原型

本轮原型只用于确认产品路径和视觉方向，不改业务代码。核心调整是把主路径从 “单词本列表 → 单词本详情 → 难度选择 → 开始练习” 调整为 “单词本列表 → 练习总览 → 开始练习”，词书和难度选择集中在总览页，不再额外设计首页快捷入口。

当前路径 首页入口 → 单词本列表 → 单词本详情 → 开始练习
建议路径 单词本列表 → 练习总览 → 直接开始
01 练习总览 承接学习 tab 或老入口，直接显示今日任务和开始按钮。 02 回忆练习 先只看英文和发音，减少拥挤信息，聚焦记忆判断。 03 答后展开 答完再看释义、例句和发音，下一词动作固定在底部。 04 换词书与复盘 换书、改难度、查看复盘不再阻断开始练习。 05 单词详情 参考词典卡视觉，重排释义、例句、搭配和发音入口。

本轮决策点

  1. 主入口保持现有单词本入口，确认练习总览是否足够承接开始练习。
  2. 练习页是否接受“回忆态”和“答后展开态”两段式交互。
  3. 视觉是否从朴素单色卡片升级为更轻、更有层次的移动端学习界面。
  4. 单词详情页是否采用“词典卡 + 练习操作”的混合结构。
