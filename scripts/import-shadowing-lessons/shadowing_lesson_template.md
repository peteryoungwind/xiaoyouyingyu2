母语者地道表达：2 个

### 1. target expression

- 音标：/ˈtɑːrɡɪt ɪkˈspreʃən/
- 类型：phrase
- 标签：daily expression、informal
- 形式：target expression、target expressions

- 释义：目标表达 / A useful expression in this lesson.
  - 例：这是一个目标表达。 / This is a target expression.

同义表达：
  - similar expression：相似表达

相关表达：
  - related expression：相关表达

解析：
- 用中文说明这个表达的使用场景、语气、搭配或常见错误。

原文例句：
  - EP1：First English sentence with target expression. / 第一句中文翻译。

### 2. another expression

- 音标：/əˈnʌðər ɪkˈspreʃən/
- 类型：collocation
- 标签：speaking、natural English
- 形式：another expression

- 释义：另一个表达 / Another useful expression in this lesson.
  - 例：我想练另一个表达。 / I want to practice another expression.

同义表达：
  - alternative expression：替代表达

相关表达：
  - useful expression：实用表达

解析：
- 用中文说明这个表达为什么地道、什么时候用。
