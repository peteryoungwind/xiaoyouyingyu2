- 标签：phrasal verb、preparation、task
- 形式：get ready、getting ready、getting ready playlist、got ready

- 释义：准备；准备好 / To prepare for something, or to make oneself ready for a task or event.
  - 例：我们需要准备好出发了。 / We need to get ready to leave.

同义表达：
  - prepare：准备
  - get set：准备好

相关表达：
  - get ready for work：准备上班
